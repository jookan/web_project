# 악보 페이지 JavaScript 구성

## 로그인·시작 화면 공통 파일

| 파일 | 역할 |
| --- | --- |
| `ambient_session.js` | 게스트 입장 상태 읽기·저장·삭제 |
| `session_guard.js` | Firebase 인증 복원 이후 시작 화면과 Aurora의 접근 상태 검사 |
| `ambient_login.js` | 로그인·회원가입 탭, 입력값 검사, 비밀번호 표시, 게스트 입장 |
| `ambient_hub.js` | Firestore 프로필 이름 표시와 Firebase 로그아웃 |
| `firebase_data.js` | 공통 인증·비공개/공개 프로필·오류 표시 |
| `firebase_nav.js` | 페이지 상단 사용자 표시와 계정 변경 처리 |
| `community_store.js` | 게시글·댓글·좋아요·팔로우의 Firestore 저장/실시간 조회 |
| `account_state.js` | 디깅/Aurora 개인 목록의 Firestore 저장과 UID별 로컬 캐시 |
| `local_files.js` | 첨부파일 원본의 로컬 보관과 열기 |

로그인과 시작 화면의 HTML에는 스크립트 경로만 두고 실행 코드는 위 파일에서 관리합니다.
화면의 접근 검사와 별도로 `firestore.rules`에서 실제 데이터 접근 권한을 검사합니다.

## 악보 기능

HTML은 `sheet_functions.js` 하나를 `type="module"`로 불러온다.
나머지 파일은 이 파일의 `import`를 따라 연결된다.

| 파일 | 역할 |
| --- | --- |
| `sheet_functions.js` | 시작점. 현재 악보 선택, 이전·다음 이동, 기능 연결 |
| `score_library.js` | 파일 선택, 중복 확인, 악보 객체 생성, 목록 버튼 |
| `pdf_viewer.js` | PDF.js 준비, PDF 읽기, 페이지 그리기, 화면 크기 대응 |
| `practice_settings.js` | BPM·박 수 검사, 연주 순서 편집·추가·삭제, 예상 시간과 현재 단계 표시 |
| `auto_turn.js` | 단계별 시간 계산, 시작·정지, 순서에 따른 자동 넘기기 |
| `metronome.js` | 자동 넘기기 단계의 박자 소리 생성 및 정지 |
| `score_storage.js` | UID별 IndexedDB의 PDF 원본과 Firestore의 악보 설정 저장·복원 |
| `vendor/pdfjs/` | 외부 PDF.js 라이브러리. 직접 수정하는 학습 코드가 아님 |

## 악보를 선택했을 때

1. `score_library.js`가 메인에서 전달받은 `selectScore(score)`를 호출한다.
2. 메인은 선택한 악보를 `activeScore`에 저장한다.
3. `showPracticeSettings(score)`가 입력값과 연주 순서를 표시한다.
4. `renderPage(score)`가 해당 악보의 현재 페이지를 그린다.

각 기능은 같은 `score` 객체를 전달받는다. 설정을 다른 객체로 복사하지
않으므로, BPM을 바꾸고 다른 악보를 선택했다 돌아와도 변경값이 유지된다.
PDF 원본은 UID별 IndexedDB에, 로그인한 사용자의 설정은 Firestore에도 저장한다.
다른 기기에서는 같은 PDF를 선택해 설정을 복원한다. 게스트는 로컬에만 저장한다.

공부할 때는 메인의 `selectScore()`부터 시작해 호출하는 함수로 따라가면 된다.

## 자동 넘기기 사용 방법

1. PDF를 추가하고 BPM과 마디당 박 수를 설정한다.
2. 연주 순서 표에서 각 단계의 PDF 페이지 번호와 연주할 마디 수를 지정한다.
3. 반복할 때는 같은 페이지 번호를 다시 넣는다. 예: `1 → 2 → 1 → 2 → 3`.
   `현재 페이지 추가`는 지금 보고 있는 PDF 페이지를 순서 끝에 넣으며,
   각 행의 `×`는 그 연주 단계를 삭제한다.
4. `처음부터 시작`을 누르면 1단계부터 자동 진행한다.
5. `정지`를 누르면 멈춘다. 다시 시작하면 첫 단계부터 시작한다.

한 단계의 시간은 `(60 / BPM) × 마디당 박 수 × 마디 수`초다.
BPM 120, 마디당 4박, 16마디면 32초다. BPM의 한 박과 입력한 박 수의
기준을 맞춰 사용한다. 페이지가 그려진 뒤부터 시간을 센다.

실행 중에는 설정을 잠근다. 수동 페이지 이동, 다른 악보 선택, 파일 선택,
탭 이탈 시 자동으로 정지한다. 마지막 단계도 설정한 시간이 지난 뒤 종료한다.
빈 연주 순서는 시작할 수 없다.

메트로놈을 켜면 자동 넘기기 중 소리가 나고 마디 첫 박을 강조한다.
페이지를 그리는 동안에는 잠시 소리가 멈추고 다음 단계가 준비되면 다시 시작한다.
메트로놈은 BPM 600까지 지원한다. PDF의 반복 기호를 자동으로 인식하지 않으므로
실제 연주할 순서와 마디 수는 직접 입력한다.

```sh
node --test tests/auto_turn.test.mjs
```
